## Dataset acquisition and preparation

[proteolysis_data_manager](proteolysis_data_manager/README.md) is the independent
library for source acquisition, integration (including source adapters),
condition protocols and analysis helpers. Half-life and BRENDA kinetics are
separate data families; the kinetics reader preserves a relational table bundle.
