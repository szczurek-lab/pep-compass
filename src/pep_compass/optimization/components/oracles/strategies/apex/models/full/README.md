# `full` APEX model

Extended pathogen ensemble (34 pathogens). 40 pretrained models, filenames `trained_all_model_*_ensemble_*`.

Source: [`machine-biology-group-public/apex`](https://gitlab.com/machine-biology-group-public/apex/-/tree/main/trained_models),
the official upstream APEX repository, path `trained_models`.

Install with `assets/scripts/downloads/apex/download_apex_models_full.sh`. Weight files are not
committed to this repository; only this README and `.gitignore` are tracked.
