# `default` APEX model

8-pathogen ensemble used in the original APEX paper. 8 pretrained models, filenames `APEX_*`.

Source: [`Yimeng-Zeng/APEXGo`](https://github.com/Yimeng-Zeng/APEXGo), path
`optimization/apex_oracle/APEX_pathogen_models`.

Install with `assets/scripts/downloads/apex/download_apex_models_default.sh`. Weight files are not
committed to this repository; only this README and `.gitignore` are tracked.
